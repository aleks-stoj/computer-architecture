### Hinzufügen der Befehle

#### auipc

![image-20250412074501557](C:\Users\Ben\AppData\Roaming\Typora\typora-user-images\image-20250412074501557.png)

- Erweiterung von **Extend** für U-Type

  ```vhdl
  when EXT_U_TYPE => immext <= instr(31 downto 12) & (11 downto 0 => '0');
  ```

- Im **PKG**, IMM_SRC_SIZE auf 3 Bit
  
  - Erweiterung ist notwendig,  da aktuell nur 2 Bit somit sind nicht mehr zustände möglich
  
- Ergänzung in **Control Unit**

  ```vhdl
  -- controls
    RegWrite & ImmSrc(2) & ImmSrc(1) & ImmSrc(0) & ALUSrc & MemWrite & ResultSrc(1:0) & Branch & ALUOp(1:0) & Jump & g_ecall;
  
  -- signal controls
    STD_ULOGIC_VECTOR(12 downto 0); -- vorher 11 downto 0
  
  -- Alle EXT_X_TYPE auf 3 Bits erweitern und U-Type definieren
    constant EXT_U_TYPE : std_ulogic_vector(IMM_SRC_SIZE-1 downto 0) := "100";
  
  -- Zuweisung von controls when U-Type
    when "0010111" => controls <= "100100000000"; -- auipc
  ```


- **ALU Control** past bereits
- **MUX** der RD1, PC und op bekommt als Eingang

  ```vhdl
  -- Wechsel zwischen PC und RD1
  pcOrRD1 <= PC when op = "0000111" else -- für AUIPC, PC bleibt die Basis
           RD1; -- für andere Instruktionen
  ```

#### bge

![image-20250412074429383](C:\Users\Ben\AppData\Roaming\Typora\typora-user-images\image-20250412074429383.png)

- **ALU**

  ```vhdl
  -- Neuen Ausgange sign hinzufügen
  Sign: out STD_ULOGIC
      
  -- sign auf 31 Bit setzen
  Sign <= sum(31);
  ```

- **Control Unit**

  ```vhdl
  -- Definieren von sign in der Alu Entity
  Sign: in STD_ULOGIC;
  
  -- Sign bit berücksichtigen
  PCSrc <= (Branch and (
  	     (funct3 = "000" and Zero) or    -- beq
  	     (funct3 = "101" and not Sign)   -- bge
  	     )) or Jump;
  ```

#### jalr

![image-20250412074433091](C:\Users\Ben\AppData\Roaming\Typora\typora-user-images\image-20250412074433091.png)

- **Control Unit**

  ```vhdl
  -- jalr hinzufügen
  when "1100111" => controls <= "111001000010"; 
  ```

- **MUX** vor PCTarget Adder

  ```vhdl
  -- Wechsel zwischen RD1 und PC
  pcOrRd1 <= PC when Jump = '0' else -- normaler Branch
             RD1;                    -- jalr: rd1
  ```

- **PC Target**
  
  ```vhdl
  -- Hochzählen von Pc ändern für jalr
  y <= std_ulogic_vector(unsigned(pcOrRd1 ) + unsigned(ImmExt)) 
         and x"FFFFFFFE" when op = "1100111" 								-- maskieren nur bei jalr
         else std_ulogic_vector(unsigned(pcOrRd1 ) + unsigned(ImmExt));
  ```

### Signale

| Signal     | auipc        | bge                       | jalr         |
| ---------- | ------------ | ------------------------- | ------------ |
| PCSrc      | 0            | abhängig (Branch & ¬Sign) | 1            |
| ResultSrc  | 00           | X                         | 10           |
| MemWrite   | 0            | 0                         | 0            |
| ALUControl | 000 (ADD)    | 001 (SUB)                 | 000 (ADD)    |
| ALUSrc     | 1            | 0                         | 1            |
| ImmSrc     | 001 (U-Type) | 100 (B-Type)              | 000 (I-Type) |
| RegWrite   | 1            | 0                         | 1            |
| Branch     | 0            | 1                         | 0            |
| Jump       | 0            | 0                         | 1            |
| SrcA       | 1 (PC)       | 0 (rd1)                   | 0 (rd1)      |
